# Owner-native public records

`createNativePublicRecordClient` composes the actual Interego browser relay transport, RDF digest/parser, CID primitive, and pinned Solid descriptor/distribution/digested-region functions. The configured relay's authenticated authorship report is the trust source, labelled `relay-attestation` in every confirmed receipt. This client does not claim independent owner key signing. Native admission readers can independently validate the same public proof and owner delegation.

Construction requires `publicData: true`, an authenticated verified-owner binding (`ownerDid`, public `podUrl`, canonical `webId`), the configured HTTPS relay origin, and the explicitly granted browser-only access credential. `connect()` calls the discovered native `get_pod_status` without a caller pod selector and checks the owner, pod name and session publishing agent. It never registers an agent or grants access to storage. Native bearer and grant credentials stay in browser memory, and anonymous public GETs use `credentials: 'omit'` with no Authorization header.

The methods are `connect`, `currentHead({graphIri})`, `load({graphIri})`, `create({graphIri,graphContent,publicData:true})`, `save({graphIri,graphContent,expectedHead,publicData:true})`, `confirm(operationId)`, `status`, and `close`. Authored RDF is bounded to 32 KiB, reads to 256 KiB, and pending operations to eight with one per graph. A private profile must never be passed to this public writer.

A confirmed receipt requires a current unforked owner-pod head, real descriptor CID, exact owner and publisher binding, verified content-bound authorship, the SDK digested named graph, matching canonical content digest, public unencrypted distribution, byte-identical anonymous public descriptor, matching anonymous graph digest, and unchanged sole head after readback. Only validated aliases from the authenticated owner's pod status can map to the verified public pod root.

Updates send the previous native head CID as `if_match`. Initial creation checks confirmed absence and reads back a sole head; the native relay does not expose atomic compare-with-absence. A concurrent initial fork is refused. A pending, failed or lost acknowledgement never means saved. The caller retains the operation ID and uses `confirm`, which checks the exact native descriptor operation ID and graph digest without republishing. Unconfirmed operations are bounded in memory; closing discards that memory and clears the transport credential. A fresh browser can read the native primary directly.

The public validators are a separate lazy SDK bundle, preserving the existing small private-key bundle. `tools/build-native-public-client.mjs` requires the reviewed Interego revision, pinned esbuild and TypeScript, validates source and dependency versions against the committed SDK lock, and records source/declaration hashes. The Solid declaration slice is copied unchanged at build time with its complete dependency closure; it avoids importing unrelated Node-only core modules into browsers. The public CID primitive uses the actual SDK implementation and its licensed dependencies.

Node tests and the Chromium owner-grant test exercise actual SDK transport, parsing, hashing and browser execution against explicit native storage/authorship contract fixtures. They do not establish live pod interoperability, production deployment, independently issued signatures or player identity creation.
